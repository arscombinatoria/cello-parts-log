弓は、予算と用途を決めたうえで、自分の楽器での発音、操作性、音色変化、身体への負担を比較して選びます。[材質](./materials.md)、[メーカー](./manufacturers.md)、[製作伝統](./making-traditions.md)は候補を探す手掛かりですが、個々の弓の評価には試奏が必要です。

## 重量・重心・剛性・しなり・反発感

| 観点 | 意味と確認点 |
| --- | --- |
| 重量 | 弓全体の質量です。表示値が同じでも、重心や持ち方によって手に感じる重さは異なります。 |
| 重心 | 質量の配分を反映する位置です。弓先の重さの感じ方、返し、移弦のしやすさを確認します。 |
| 剛性 | 力に対する曲がりにくさです。材質だけでなく、スティックの太さや形状にも依存します。 |
| しなり | 荷重に対するたわみ方です。弦を捉える感触や強奏時の追従性を、普段の運弓で確認します。 |
| 反発感 | 弓が戻る速さや跳ね方についての演奏者の感覚です。剛性だけの数値には置き換えられず、スピッカートなどで評価します。 |

反り（スティックのカーブ）は、荷重で生じるしなりとは別の形状上の要素です。毛の量・長さ・摩耗、巻線、フロッグ、金具も重量配分や使用感に関わります。軽い弓や硬い弓が、すべての奏者にとって扱いやすいわけではありません。

## 同じ条件で比較する方法

1. 普段の楽器・弦・松脂・部屋を基準に、候補を交互に弾きます。試奏中に弦や松脂を替えると、弓による差を見分けにくくなります。
2. 毛の状態と張り具合を確認し、各弓に適した通常の張りで比べます。張りすぎて条件を揃えようとせず、不明点は店や工房に確認します。
3. 開放弦ロングトーン、音階、移弦、デタシェ、軽いスピッカート、普段の曲を毎回同じ順で試します。
4. 可能なら10〜15分程度弾き、手首・前腕の緊張や疲労も記録します。無理をして弾き続ける必要はありません。
5. 重量などの仕様、試奏での観察、好みを分けて記録します。「柔らかく感じる」は主観、「同じ弱音のフレーズでかすれが減った」はその条件での観察であり、一般的な性能保証ではありません。

## 試奏時の確認項目

| 観点 | 確認する内容 |
| --- | --- |
| 発音 | 低弦や弱音で音が遅れず立ち上がるか、不要なノイズが出ないかを確認します。 |
| 音色・表現 | 同じフレーズで芯、厚み、明るさを変えられるか、弱音から強音まで制御できるかを確認します。 |
| レガート | 弓元から弓先まで音量と音のつながりを保てるか、返しが不自然にならないかを確認します。 |
| 操作性 | 移弦、分散和音、細かな返しを、余分な力を入れずに行えるかを確認します。 |
| 安定感 | 低弦の強奏や重音で音がつぶれないか、ロングトーンが揺れないかを確認します。 |
| 反発 | デタシェやスピッカートで、跳ね方が過敏すぎず、戻りが遅すぎないかを確認します。 |
| 聴こえ方 | 自分の耳元の印象に加え、可能なら離れた位置で聴いてもらい、音の届き方を確認します。 |
| 身体への負担 | 弓先を支えるときや弓元で返すときに、手首や前腕が固まらないかを確認します。 |

## 経験と用途に応じた優先順位

| 経験 | 優先する判断材料 |
| --- | --- |
| 初心者・再開者 | 無理なく弦を捉えられるか、発音や弓順が安定するかを優先します。予算内で複数本を比較し、必要に応じて教師にも確認してもらいます。 |
| 中級者 | レガートと反応速度を両立できるか、現在苦手な運弓と得意な運弓の両方で比較します。 |
| 上級者 | 弱音、音色変化、強奏時の追従性など、曲目や演奏場所で必要な表現を再現できるかを確認します。 |

| 用途 | 比較する条件 |
| --- | --- |
| ソロ | 強弱と音色の幅、遠くでの聴こえ方、強奏時の安定感を確認します。 |
| 室内楽 | 他の楽器との音のつながり、弱音の制御、細かなアーティキュレーションを確認します。 |
| オーケストラ | 合奏での発音の揃えやすさ、奏法の切り替え、長時間の身体負担を確認します。 |
| 練習・持ち運び・予備弓 | 耐久性、気候変化への耐性、毛替えなどの維持費を含めて比較します。カーボン系も候補ですが、弓先・弓元の操作性は試奏で確かめます。 |

古楽を目的にする場合は、材質や価格帯とは別に[バロック弓と現代弓](./baroque-and-modern-bows.md)の設計・奏法の違いも検討してください。

## 相性・個体差・調整状態

同じ材質・メーカー・モデルでも、個体差と調整状態により印象は変わります。楽器本体、弦の種類と状態、松脂、部屋、奏法を記録し、条件が変わった場合は評価し直します。音量だけが増えても、弱音や操作性が犠牲になっていないかを確認してください。

毛替え、反り直し、スクリューやフロッグの不具合、割れや修理跡の判断は工房に相談します。調整不良と弓本来の性格を混同しないため、状態に疑問がある個体は点検を受けてから比較します。作家弓・オールド弓の鑑定や保存状態については[メーカー比較ページの補足](./manufacturers.md#作家弓オールド弓について)も参照してください。
