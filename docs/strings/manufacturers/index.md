## 表の読み方

シリーズ一覧には代表的な製品を掲載しており、全製品・全サイズを網羅していません。現行製品かどうかを確認した資料と確認日は、各記事の補足に記載しています。資料への掲載を確認できなかった製品も、終売とは断定できません。購入時には、型番ごとの仕様・販売状況を公式情報で再確認してください。

材質や型番などの仕様と、メーカーによる音色・反応の説明は区別して読みます。「暖かい音」「速い反応」などはメーカーが訴求する設計上の特徴であり、共通条件での測定結果を示すものではありません。

一方、個別記事で「公式説明」「設計」と明記した箇所以外の音色・張力感・用途は、既存記事に基づく主観的な比較の目安です。試奏条件が明記されていない評価は未検証であり、製品の性能として断定できません。音色・弾き心地を比べるときは、楽器、弓、松脂、弾き方、部屋、弦の使用期間を揃えます。

物理的な張力と押弦時の張力感は区別します。張力の数値を比較するときは、弦長・調弦条件も併せて確認してください。

価格帯は概算であり、購入時期・地域・単弦かセットかによって変わります。
