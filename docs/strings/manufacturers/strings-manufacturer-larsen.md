Larsen Strings のチェロ弦シリーズを、客観仕様と主観的な音色傾向を分けて整理するページです。

## メーカー概要

- デンマークの弦メーカー
- Original、Magnacore 系、Il Cannone、Sovereign など複数ラインを展開
- 発表・発売時期は Sovereign（2026年4月24日発表、公式告知では2026年5月から世界展開）、Aurora（2021年公開）、Il Cannone（2020年リリース）、Magnacore Arioso（2017年フルセット完成）以外は今回確認できた一次資料では未確認

## シリーズ選定の補足

### Original

Original は、張力区分だけでなく楽器の弦高や調整状態によって左手の負担が変わります。

### Soloist

Soloist を Original と比較するときは、耳元の音量感とホールでの聴こえ方を分けて確認してください。

### Magnacore

Magnacore と Magnacore Arioso は別設計として比較します。

### Magnacore Arioso

Magnacore Arioso は、一覧表のとおり A/D と G/C で張力・コアの設計が異なるため、セット全体を「低張力」と一括りにせず、各弦の発音とフレーズのつながりを確認します。

### Il Cannone

2系統を混用する場合は、弦間の音色差に加え、強弱や会場規模に応じた扱いやすさを確認します。仕様上の互換性は、どの楽器でも同じバランスになることを意味しません。
