## 表の読み方

シリーズ一覧は代表例で、全製品・全サイズの網羅を保証するものではありません。現行性を確認した資料と日付は各記事の補足を参照し、購入する型番の仕様・販売状況を公式情報で再確認してください。掲載を確認できなかったことは、終売を意味しません。

材質や型番は仕様として扱います。メーカーの「暖かい音」「速い反応」などの説明は設計上の訴求で、共通条件での測定結果ではありません。個別記事で「公式説明」「設計」とした箇所以外の音色・張力感・用途は、既存記事の主観的な比較目安です。試奏条件が明記されていない評価は未検証であり、製品の性能として断定できません。

音色・弾き心地を比べるときは、楽器、弓、松脂、弾き方、部屋、弦の使用期間を揃えます。物理的な張力と押弦時の張力感も区別し、張力の数値は弦長・調弦条件と併せて確認してください。価格帯は購入時期・地域・単弦かセットかによって変わる概算です。
