## 概要

チェロ用エンドピンの購入・試奏候補を、メーカー・ブランドごとの製品構成から探すためのページです。材質、棒の構造、径、ソケット（楽器側の固定部品）との適合、交換方式を比較します。市場シェアや売上の順位を示すものではなく、すべての製品を網羅した一覧でもありません。

同じメーカーでも、モデル、材質、中空／ソリッド、重量、径などで条件が異なります。メーカー名だけで音質は判断できません。音響・演奏感について報告されている違いや試奏条件は、[材質別の比較](./endpins-materials.md)を参照してください。

## 各メーカー・ブランドの短い解説

### MITSUKE / 見附精機工業 {#mitsuke}

[見附精機工業の公式ショップ](https://www.vcyoyo-mitsuke.jp/shopbrand/009/O/)には、真鍮・チタン・カーボンの棒と、これらにタングステンなどを組み合わせた製品があり、8mm・10mmから比較できます。MITSUKEの製品名である[Triple Brillante](https://www.vcyoyo-mitsuke.jp/shopdetail/009000000008/009/O/page1/recommend/)は中心からタングステン・チタン・真鍮の3層です。[Quartet](https://www.vcyoyo-mitsuke.jp/shopdetail/009000000026/009/O/page1/recommend/)は先端側がその3材、後部がカーボン・真鍮という構成です。

棒の交換候補を探すときは、材質名に加えて先端まで同じ材質か、既存ソケットに合う径かを確認します。Quartetの公称値は50cmで8mmが約140g、10mmが約255gです。径・長さが違う製品同士では重量も変わるため、注文する仕様で照合してください。両製品の音響評価は[材質別記事のMitsuke複合製品](./endpins-materials.md#composites)にまとめています。

### BENDER {#bender}

[販売元FiedlerのBENDER棒のページ](https://www.fiedler-cases.de/bender-endpin-for-cello)では、製造者をBender Marinetechnikと記載し、棒をソケットなしで販売しています。掲載仕様は10mm・約60cmで、アルミ中空約100g、カーボン中空約60g、チタン中空約90g、チタンソリッド約200g、真鍮ソリッド約390gです。重量は棒と先端の値で、一式の値ではありません。チタンソリッドはチタン先端、他の4種はステンレス先端です。

[別売のBENDERソケット](https://www.fiedler-cases.de/bender-end-button-for-cello-endpin)はアルミ製で、大きなコレットナットで棒を全周から締め付けます。楽器への差し込み部には細かなねじがあり、一般的な押し込み式ソケットと取り付け条件が異なります。ソケットごと見直す場合は、[販売元が案内する弦楽器製作者による取り付け](https://www.fiedler-cases.de/instrument-endpins)を前提に工房へ相談してください。Fiedlerが販売していても、BENDERとFIEDLER名義の製品は分けて比較します。

### New Harmony Music {#new-harmony}

[公式製品情報](https://newharmonymusic.com/products/)は、チェロ用カーボンの中空／ソリッドと8mm・10mm径を掲載しています。20インチに加え24・28インチの長さ、熱処理した金属先端または交換式カーバイド先端が比較項目です。アルミ中空とステンレスソリッドも掲載されていますが、カーボンと同じ寸法展開とは限りません。

棒と専用ソケットの両方を検討できます。ソケットは棒用8mm・10mmとは別に、テーパー大端径23.5・25.5・27.5mmがあり、6度の角度付きは大端径27.5mmのみです。既存ソケットで棒だけ交換する場合も、ねじがカーボン表面を直接押す方式か確認してください。メーカーは過度な締め付けによる表面損傷に注意を促しています。長く出す場合は、必要な長さでのしなりと固定状態も確認します。

### Bois d’Harmonie {#bois}

[公式のClassic](https://boisdharmonie.net/en/our-fittings/endpins-endbuttons/)は木製ソケットとカーボン棒、タングステンカーバイド先端の組み合わせです。木材名はソケットの選択肢で、木製の棒という意味ではありません。チタンソリッド棒と軽量チタン棒への交換も案内されています。カーボンと軽量チタンの中空／ソリッド、棒径・長さ・重量はこのページでは明記されていないため、対象仕様を問い合わせます。

ソケットの標準テーパー最大径は25mmで、27mmや最大29mmまでの特注も案内されています。Mirecourt／Baroqueは最大長41cm・2分割の着脱式として掲載され、Classicと構造が異なります。ソケットの適合に加え、演奏後に棒を収納するか取り外すかもモデルごとに確認してください。

### Bowed Acoustics {#bowed-acoustics}

[公式Cello End Pin](https://bowedacoustics.com/products/cello-end-pin)は、ステンレス棒と交換可能な硬化鋼先端、削り出しアルミ製ハウジングを組み合わせています。内部の割りコレットとDelrin製テーパーコーンが特徴で、ソケットを含む固定構造から比較する候補です。

公式ページには棒径・長さ・重量や中空／ソリッドの別が明記されていません。旧工房試奏に登場する8mm棒の寸法を現行品へ転用せず、現在注文できる棒とハウジングの仕様、交換部品、楽器内部への収納を確認してください。

### GEWA {#gewa}

[公式一覧](https://gewastrings.com/en/products?categoryEntityId=21326)には、Standard、カーボン、Resonant、Arc、Solipinなどが掲載されています。[Standardの10mm・52cm](https://gewastrings.com/en/product/gewa-cello-end-pin-standard-52cm-o10mm/418)は金属棒と黒檀ソケット、[カーボン10mm・60cm](https://gewastrings.com/en/product/gewa-cello-end-pin-60cm-o10mm-carbon-fibre/436)は交換式クローム先端を持つ製品です。径が同じでもソケットのテーパー寸法を照合します。

[Resonant](https://gewastrings.com/en/product/gewa-cello-end-pin-resonant/26248)は10mmカーボン棒に4mmの穴を設け、ポリアミド製ソケットを組み合わせた製品で、40・50・60cmの選択肢があります。[Arc](https://gewastrings.com/en/product/gewa-cello-end-pin-arc-61cm-o10mm-carbon-fibre/437)は10mm・61cmのカーボン棒と樹脂製ソケットです。[Solipinの棒単体](https://gewastrings.com/en/product/gewa-cello-end-pin-rod-solipin/18138)はチタン芯・真鍮外層の10mm・50cmで、[タングステン芯の別モデル](https://gewastrings.com/en/product/gewa-cello-end-pin-solipin-tungsten-core/26125)もあります。これらはGEWAの製品名であり、同じカタログにあるULSAやStahlhammerとは分けます。

### ULSA {#ulsa}

[Ullsperger Musikzubehoerの公式製品情報](https://www.ulsamusic.com/unsere-produkte/cellostachel/)では、ULSAのUSA、Solitär、Rohr、L-Modell、Knickなどを掲載しています。カーボン、チタン、金属中空棒などを木部・金具と組み合わせて選べる点が比較対象になります。USAやSolitärには52・62cmの選択肢があり、USAのチタンには10mmと軽量8mmが掲載されています。シリーズ名のUSAを生産国の表示として読まないよう注意してください。

Rohrには硬化鋼先端や交換式ねじ込み先端の仕様があり、Knickは角度付きの伸縮管を使う特殊型です。カーボンの中空／ソリッド、Knickの角度・可動範囲・重量など、この公式ページだけで確定できない仕様は問い合わせます。木部と棒径、取り付け、収納方法を製品番号で確認してください。

### Glasser {#glasser}

[公式ページ](https://glasserbows.com/endpin/)はチェロ用カーボンエンドピンXCENDPIN1を掲載し、独自の締め付け機構を説明しています。[公式ショップ](https://shop.glasserbows.com/products/cello-endpin)では24インチ長とされています。固定部を含めてカーボン製品を比較する候補です。

棒径、中空／ソリッド、重量、先端の仕様はこれらのページでは明記されていません。棒とソケットの供給範囲、既存部品との適合、収納時の長さを確認してください。コントラバス用XBENDPIN1の仕様とは区別します。

### TekPin {#tekpin}

[公式ショップ](https://www.tekpinusa.com/shop)には、ProとConservatoryの各モデルにステンレス／カーボンの選択肢があります。TekPinはブランド・製品名として扱い、ProやConservatoryを別メーカーには数えません。[公式FAQ](https://www.tekpinusa.com/faq)では、主軸を垂直位置で使用する特殊構造に加え、通常の直線型としても使えることを案内しています。

FAQは主軸と延長棒を分け、延長棒は標準ステンレスとオプションのチタン、主軸はステンレスとカーボンを説明しています。注文モデルで選べる組み合わせ、必要な長さ、収納状態、姿勢への影響を確認します。付属アダプターコーンがあっても、メーカーは専門家による取り付けを必須としています。「元の穴の加工が不要な場合がある」という説明を、すべての楽器に無加工で適合する意味には取りません。

### FIEDLER {#fiedler}

[公式CARBONMETAL Copper](https://www.fiedler-cases.de/FIEDLER-endpin-for-cello-CARBONMETAL-copper)は、純銅のソリッド芯を薄いカーボン層で被覆した10mmの棒です。CARBONMETALはFIEDLERの製品シリーズで、カーボン単体棒や銅単体棒とは分けて比較します。メーカーはBender型の10mm・全周締め付けソケットを推奨しています。

既存ソケットを使えるか、棒だけ交換するかを工房に相談し、長さ、先端、重量とその集計範囲を確認してください。メーカーの音響上の説明と条件付きの試奏報告は[材質別記事の銅複合製品](./endpins-materials.md#copper)にまとめています。

### 販売情報で確認した候補：Stahlhammer {#stahlhammer}

[販売元GEWAの掲載](https://gewastrings.com/en/product/stahlhammer-cello-endpin-foldable-carbon-fiber-silver/26554)では、カーボン製の角度付き製品について、25度、径11mm、Mediumの長さ27〜47cm・重量125g、交換先端1個付きとされています。これは販売情報で、メーカー自身の現行製品資料は今回十分に確認できなかったため、上の比較表には含めていません。GEWAの自社シリーズとも断定しません。

特殊型の候補にする場合は、現在供給される型番と材質、長さの測定範囲、ソケット一式の適合、楽器内部への収納、交換部品を販売元と工房で確認してください。

## 目的から候補を探す

以下は製品構成から選んだ候補です。音質の順位や、メーカー単位の効果を示すものではありません。

| 目的 | 比較候補 | 確認すること |
| --- | --- | --- |
| 複数の材質を比較したい | MITSUKE、BENDER、ULSA | 同じ径・必要な突出長で比較できるか、先端やソケットも変わるか |
| カーボンの中空／ソリッドを比較したい | New Harmony Music | 同じ径・長さの製品を選べるか、先端・重量・固定方式の違い |
| 標準的な直線型を探したい | GEWA Standard、BENDERの棒、ULSAの直線型 | 棒単体の交換かソケット一式か、径とテーパーの適合 |
| 角度付きなど姿勢に関係する特殊型を探したい | New Harmonyの6度ソケット、ULSA Knick、TekPin | 角度を設ける部位、突出長、楽器の傾き、収納・着脱方法 |
| ソケットを含めた構造から見直したい | BENDER、Bowed Acoustics、New Harmony、Bois d’Harmonie | 全周締め付けやコレットの方式、楽器側の適合と工房施工 |
| 金属とカーボンを組み合わせた棒を探したい | MITSUKE Quartetなど、FIEDLER CARBONMETAL Copper | 芯・外層・前後の構成、重量、固定方式 |

## 購入・試奏前の確認事項

| 確認項目 | 購入・試奏時に照合する内容 |
| --- | --- |
| 径と固定方式 | 現在のソケットが受ける棒径、固定方式、棒の表面との適合。8mm・10mmという呼称だけで互換性を決めない |
| 交換する範囲 | 棒だけ交換可能か、ソケット交換が必要か。ソケットのテーパー径・形状、取り付けや加工の要否 |
| 棒の構造 | 中空／ソリッド、複合材なら使う部位、管の肉厚など。材質名だけで構造を推定しない |
| 長さと重量 | 全長と必要な突出長、ソケット内で保持される長さ。重量が棒だけか先端込みか一式か |
| 先端と床 | スパイクの材質・形状、交換可否、ゴムキャップ、ストッパーや使用する床との相性 |
| 収納性 | 楽器内部へ収まるか、内部部品に干渉しないか、取り外す必要があるか、ケースに収まるか |
| 演奏中の安定性 | 必要な突出長でのしなり、滑り、固定の緩み。長く出した状態でも確認する |
| 特殊構造と姿勢 | 楽器の傾き、椅子・体格との組み合わせ、可動部の固定、普段の構えを保てるか |

楽器側の加工、ソケット交換、固定不良への対応が必要な場合は、購入前に弦楽器工房へ相談してください。試奏では、取り付けの適合と演奏姿勢を確認したうえで、[材質別記事の試奏時の観点](./endpins-materials.md#試すときの観点)に沿って比較します。
